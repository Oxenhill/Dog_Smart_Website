# Dog Smart Training & Behaviour — site

Replacement for the Wix site at dogsmarttrainingbehaviour.co.uk, built
the same way as [Briarrose Gundogs](https://github.com/Oxenhill/Briarrose_Gundogs):
Next.js (App Router) + Sanity CMS + Tailwind CSS v4, deployed on
Vercel.

See `CLAUDE.md` for the working notes on brand, structure, and status,
and the Notion page "Dog Smart & Briarrose: Off Teachable & Wix" for
the full project plan.

## Run it locally

```bash
npm install
npm run dev
```

Sanity isn't wired up yet — see CLAUDE.md's Status section for what's
needed before that step.
